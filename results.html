Quick Start

Four commands to a running fleet.

Copy the block, or copy a single line.

terminal — bash
  1. 1 git clone https://github.com/SouthpawIN/bot-wiki.git
  2. 2 cd bot-wiki
  3. 3 make install
  4. 4 make verify

Next step

Then open bots/klerik/BOT.md and edit the mission line. The system picks it up on the next loop.

Full request path: see Apparatus.

Requirements

Node 20 or newer, git, and a Hermes Agent runtime. No database, no dashboard.

Read policy

Paths in bots/ and skills/ are read directly from disk. .system/ is read-only to every bot.

Questions from the Bench

01

What is Bot Wiki built on?

Hermes Agent by Nous Research.

02

Do I need a database?

No. Every bot is one folder of markdown; the wiki is the file tree.

03

Which bots are live?

Klerik is live. The other eight are seeding, paused or blocked — see Specimens for each status.

04

Can a bot edit the validator that judges it?

No. Klerik maintains every other bot and is refused any write to .system/. See Safety Interlocks for the hold points.
