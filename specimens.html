Specimen 01 · Klerik

The method, and the only live bot

Live signal

Mission

Klerik maintains all eight other BOT.md files and repairs the index when a path goes stale. It reads bots/, never writes outside them.

Scope

bots/ only

Validator

.system/validate.sh

Hold-point rule

The validator at .system/validate.sh judges every change Klerik makes, and Klerik is forbidden to edit it.

Read the interlocks before you release a hold point.

Open the file

bots/klerik/BOT.md

Run the validator

bash .system/validate.sh
